# Retention Notes

Short-form retention in VidGen usually follows this arc:

1. Hook
2. Tension
3. Reveal
4. Resolution
5. CTA

## What keeps viewers watching

- Start from a visible contradiction, not a generic intro.
- Keep each scene to one idea.
- Prefer concrete numbers, mechanisms, or consequences over abstract claims.
- Reveal the answer only after the hook has created an open loop.
- Let visuals and narration carry different parts of the same idea instead of repeating each other.
- Finish with a small unresolved question or teaser, not a summary.

## Structure checks

- Hook should be short and scroll-stopping.
- Scene pacing should stay tight enough to feel intentional.
- Every line should earn its runtime.
- If a file feels like notes rather than a script, move it to `references/`.
